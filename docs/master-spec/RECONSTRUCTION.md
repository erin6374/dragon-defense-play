# Independent reconstruction blueprint — 0.1.0
This is a behavioral and architectural specification, not a copy of source. Existing game/mesh bytes are not required to design an independent equivalent, but exact school recreation requires authorized plans or measurements and a complete per-parcel evidence dataset. Exact parity additionally requires unresolved tuning tables, asset dimensions and accepted visuals. Do not claim pixel-perfect recreation from current evidence.

## Proposed implementation interfaces (engine-neutral, not descriptions of actual JS APIs)
- WorldConfig: coordinate system, scale, georeferenced anchor, camera limits, road corridors, playable and decorative depth, allowed parcel polygons/holes, time-of-day table. Convert from source coordinates once; label local units. For observed integration viewer conversion x+255.88, z+22.06; do not assume Unity meters until scale calibrated.
- Parcel: stable string ID, footprint ring(s)/holes, ground elevation, height, story count, front orientation, facade template + overrides, use/interior type, material IDs, LOD, source provenance, damageable/background/provisional flags. School special ID 1003073; provisional frontage 1007130 near 1007129 requires non-overlap ownership. Separate canonical raw cadastral polygon from provisional visual/collision extension. District IDs stable, never array order across revisions without migration.
- SimState: simulation tick, seed/PRNG state, difficulty/wave/chapter, healths, score, lives, powers, active entities, chapter phase, camera/input state; keep presentation only state separate. Fixed delta step; emit causal events with stable ID, tick, source/target, world point, energy and attribution. 
- Entity: ID, kind, transform, velocity, bounds, material/use, state, source/owner, collision layers. Meteor: size, type, hp, velocity, threat layer, origin, parent/fragment tier, boss/grounded flags. Dragon: position/velocity, pose/action, life/health, cooldowns; projectile muzzle and aim ray. BuildingDamage: monotonic local strikes/component failures, remaining support and per-parcel health; track linked geometry/colliders. Fire: owner parcel/component, source event, location, intensity, lifespan, suppression. RoadUnit: lane, route, role, desired speed, stun, damage and recovery.
- InputAction: press/hold/release, movement vector and aim world ray, fire/wind/gas/buster/pause/settings. UI updates from authoritative state. Render bridge reads state and events; no gameplay side effects from drawing or QA screenshots.
- Lifecycle: initialize assets -> menu -> training/skip -> wave active -> completion -> chapter calm/cleanup/fade/cinematic/departure -> next wave -> final choice/defeat -> replay. Director sandbox isolated; no unsolicited campaign spawns. Pause simulation safely; reset resource pools, pending timers, input, physics and UI.
- Collision: swept descending segment against ground y=.7 (observed), roof and polygon sides; earliest t in [0,1] wins, use actual point. Check polygon holes, shared boundaries and active/breached structures. Apply local impulse/damage only to owner; distinct shock event if explicitly permitted. Fireball ray closest obstruction then AOE with defined radius and layer filter. Distinguish physical projectile effects from VFX.
- Progressive damage: derive local component vulnerability from material and support (glass, masonry, columns, beams, floor, roof); localized hits and component detachment; aggregate damage to remaining support; terminal collapse only at appropriate health/support threshold; rubble persists, repair reconstructs. Separate distant visual-only destruction from playable damage accounting.
- Rendering: genuine 3D city, angled tracking camera, distant skyline, depth-ordered threats, lighting phases, real mesh facade details and windows; VFX anchored to events; batch instanced repeat geometry, pool transient particles/lights, adaptive pixel ratio. Audio cues and accessible HUD mirror state.
- Asset manifest: id, revision, source URI/capture date, license/credit, units/axis, pivot, mesh/material/texture hashes, LOD, collider/structural IDs, bounds, reference confidence, derived-from hash. Never distribute restricted reference images; regenerate from licensed sources. Build asset import and validation offline.
- QA harness: seeded fixture scenarios using production paths, reset/replay, screenshot/motion captures with fixed camera and seed, performance logger and strict acceptance matrix. Separate artificial QA intervention from human gameplay. Record exact SHA and seed.

## Build from nothing: dependency order
1. Establish deterministic pure rules, input/state/event model and fixture tests; blockout camera and world grid with explicit units. Record unresolved rules in decision register; do not assume defaults approved.
2. Implement tutorial, basic flight/interception, layered meteors, waves and scoring, first-hit ownership, HUD, pause/replay. Exercise actual inputs at both map ends.
3. Model authorized school BIM or independently reconstruct from approved plans/measurements, with recognizable exterior/interior. Derive performant mesh, collision and component graph. Populate rowhouse templates and individual landmarks from dated references; fit footprint/height/roads; verify no floating parts/overlap. Obtain actual model inventory and licensed asset source manifests. Background expansion opt-in.
4. Implement parcel damage, structural failures, localized fire, debris, repair; traffic lanes, wind, gas, emergency and military roles; chapter objectives, settlement and endings; verify every contract as it lands.
5. Add Paulo source rig/animations, old fallback, realistic motion and breath origin; cinematic VFX, skyline, lighting, audio, HUD. Match target art with actual captures and owner approval. All effects follow source events.
6. Browser launch/package, cache version, instrumentation, baseline hardware tests and unassisted full campaign; verify Android independently. Only then certify browser release. 
7. Unity path: import engine-neutral fixtures and high-quality source assets, map transforms/units and material channels, reimplement presentation in HDRP, validate fixture parity, benchmark RTX3060; no requirement to preserve browser renderer internals. Reuse source asset export and do not remesh unnecessarily.

## Still needed for truly independent exact recreation
Complete historic requirements crosswalk; authoritative per-wave spawn/escort/ending/scoring/power and input timing tables; damage/health and fire cap rules; exact camera and street dimensions; parcel data and asset recipe per landmark, source school measured dimensions/interior evidence, all model/texture/rig metadata and animation keyframes, audio cue inventory, full settings/accessibility behavior, exact budgets for pools and LOD per train, calibrated performance target on target devices, owner-approved art shots and playtest observations. Until these are audited, this is a structured reconstruction blueprint, not a complete lossless recreation package.
