TECH FREIRE DRAGON DEFENSE — v5.3.1 WINDOWS PREVIEW
===================================================
Experimental development preview — not production v5.2.3.

START ON WINDOWS
1. Extract the entire downloaded ZIP to a normal folder.
2. Double-click PLAY-PREVIEW.cmd inside that extracted folder.
3. The launcher checks Python 3, starts a local web server and opens your browser.
4. If the browser does not open automatically, visit:
   http://127.0.0.1:8769/
5. Keep the command window open during play. Close it when done.

IMPORTANT: Do not double-click index.html. The browser blocks the JavaScript
modules when this game is opened using file:// rather than http://.

NEW WIND BREATH CONTROLS
- Quick left mouse click: fireball.
- Hold LEFT mouse at least 0.7 seconds, release: release a gust.
- Right mouse click: gas attack (unchanged).
- Wind recharges in approximately 4 seconds.
- Touchscreen: long-press and release the FIRE button.

v5.3.1 WIND EFFECTS
- Deflect meteors and disorient helicopters (existing ability).
- Push pedestrians slightly; lightweight bicycles/scooters move most.
- Cars move less. Vans/trucks move still less; buses and fire trucks
  barely shift. Ground push is bounded per gust, with no added injury.
- Swirling ground-dust and a small number of moving scraps, in two
  GPU-instanced particle batches with preset capacity limits.
- Nearby building smoke bends downwind and becomes thinner briefly.
- Existing street-fire / explosion smoke puffs are also nudged by wind.
- Breath still suppresses school fires (not all neighborhood fires).

KNOWN LIMITATIONS / PLAYTEST FOCUS
- Wind effect intensity, feel, and hardware FPS require hands-on testing.
- Browser QA uses headless software WebGL, not a Windows graphics card.
- The distant skyline graphics are still under visual review.
- This ZIP is a browser game preview with a Windows launcher; not an APK.
- The code changes are isolated on GitHub draft PR #2, not production.

REPORT PLAYTEST FEEDBACK
Please note: what level you played, which target you blew at, whether
wind pushed it too far/not far enough, apparent smoke and debris, and any
FPS drops or console errors (F12).
